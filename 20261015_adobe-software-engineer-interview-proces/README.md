# AI 면접 정책 레이더 (AI Interview-Policy Radar)

## 한 줄 설명
Hacker News에 새로 올라오는 "기술 면접 후기/가이드" 글 중, 회사가 **면접 중 AI 도구(ChatGPT·Copilot 등) 사용을 허용/금지**한다고 언급한 글만 교차 필터링해 텔레그램으로 알려주는 무인(run-once) 레이더입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔나
오늘의 트렌드 소스는 "Adobe Software Engineer Interview: Process, AI Rules and How to Prepare" (HN)였습니다. 이 글의 핵심은 단순한 면접 후기가 아니라 **"면접에서 AI 사용이 허용되는가"라는 회사별 정책 차이**입니다. 2025~2026년 들어 각 테크 기업이 코딩 면접에서 AI 도구 허용 여부를 제각각 다르게 정하면서(완전 금지/부분 허용/케이스별 재량) 구직자 입장에서는 이 정보 비대칭이 실질적인 리스크가 됩니다. 기존에 만든 프로젝트 목록에는 "면접/채용 AI 정책"을 다루는 레이더가 없어 중복되지 않는 새로운 틈새입니다.

## 동작 방식
1. Hacker News Algolia 검색 API(무료, 키 불필요)로 최근 48시간 내 올라온 "interview" 관련 신규 글을 여러 쿼리로 수집합니다.
2. 제목/본문에 "면접 관련 키워드"와 "AI 관련 키워드"가 **동시에** 등장하는 글만 신호로 간주합니다(교차 필터링).
3. `data/seen_ids.json`에 이미 알린 글 ID를 저장해 중복 알림을 방지합니다.
4. 새로 감지된 신호만 텔레그램으로 전송하고 즉시 종료합니다(데몬 아님, 매일 1회 실행 전제).

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` : 기존 파이프라인에 이미 설정된 텔레그램 봇 토큰 그대로 사용
- `TELEGRAM_CHAT_ID` : 기존 파이프라인에 이미 설정된 채팅 ID 그대로 사용
- 그 외 추가 API 키 없음 (HN Algolia API는 공개·무료·무인증)
