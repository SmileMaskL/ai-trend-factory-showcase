# 게임 디컴파일 & AI 포팅 레이더

## 한 줄 설명
GitHub에서 활발히 업데이트되는 "게임 디컴파일 / ROM 해킹 / 게임 보존" 오픈소스 저장소와,
HN(Hacker News)에 새로 올라온 관련 토론을 매일 교차 수집해 텔레그램으로 알려주는
무인 큐레이션 레이더 봇입니다.

## 왜 이 아이디어인가
오늘의 트렌드 "Xbox is officially embracing the chaos of AI-powered game ports"는
마이크로소프트가 게임 디컴파일·에뮬레이션·리버스엔지니어링을 공식적으로 받아들이기 시작했다는
신호입니다. 이 흐름은 이미 존재하던 "레트로 게임 디컴파일/ROM 해킹" 오픈소스 커뮤니티(SM64 decomp,
OoT decomp류 프로젝트)에 AI 도구가 결합되면서 더 활발해질 가능성이 큽니다. 기존 생성 프로젝트
목록에는 "AI 에이전트/MCP/RAG GitHub 레이더", "컴파일러 release note 레이더" 등은 있었지만,
게임 디컴파일/보존이라는 완전히 다른 개발자 커뮤니티(레트로 게이밍·ROM 해킹 개발자)를 대상으로 한
신호는 없어 겹치지 않습니다.

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` (필수, 파이프라인에 이미 설정되어 있음)
- `TELEGRAM_CHAT_ID` (필수, 파이프라인에 이미 설정되어 있음)
- `GITHUB_TOKEN` (선택): 설정하면 GitHub 검색 API rate limit이 완화됩니다. 없어도 무인증으로 동작합니다.

텔레그램 환경변수가 없는 실행 환경에서도 실패하지 않고, 결과를 콘솔(stdout)에 출력한 뒤
정상 종료합니다.
