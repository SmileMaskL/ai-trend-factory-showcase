# Data Center Permit Policy-Gap Radar

**한 줄 설명:** 주정부/지자체가 "데이터센터 허가를 중단하겠다"고 공개 발표한 뒤에도 실제로는 허가·승인이 계속 진행되는 "정책 선언 vs 실제 행정 집행" 괴리 신호를 HN + Google News에서 매일 교차 포착해 텔레그램으로 알려주는 무인 레이더입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔는가
오늘의 트렌드 기사("Texas Said It Would Halt Data Center Permits. The State Is Pushing Ahead Anyway")는 텍사스주가 데이터센터 허가를 중단한다고 공식 발표했지만, 실제 행정 절차는 계속 진행되었다는 내용입니다. 이는 단발성 사건이 아니라 AI 붐으로 전력망 부담이 커지는 미국 각지에서 반복될 가능성이 높은 패턴입니다(발표는 '중단'이지만 실제론 '계속 승인'). 이 프로젝트는 이 한 건의 뉴스를 일반화해, 앞으로도 같은 유형의 "허가·모라토리엄·그리드 제한 발표 vs 실제 계속 진행" 신호가 뜰 때마다 가장 먼저 포착하는 상시 레이더로 만든 것입니다. 기존에 만든 프로젝트들은 AI 규제 담론, AI 말투, PyPI 글루트 등 소프트웨어/AI 담론 쪽이었고, 이 프로젝트는 완전히 다른 도메인(에너지/부동산/인프라 행정)을 다루므로 중복되지 않습니다.

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` : 기존 파이프라인에 이미 설정된 텔레그램 봇 토큰 재사용
- `TELEGRAM_CHAT_ID` : 기존 파이프라인에 이미 설정된 채팅 ID 재사용

새로운 API 키는 필요 없습니다 (HN Algolia API, Google News RSS 모두 키 없이 무료로 사용 가능).
