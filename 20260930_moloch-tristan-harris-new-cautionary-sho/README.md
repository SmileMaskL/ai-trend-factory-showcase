# Moloch Index — AI 레이스 vs 안전 예측시장 신호봇

하루 한 번, Manifold Markets의 무료 공개 예측시장 API에서 "AI 능력 경쟁(레이스)" 계열
질문과 "AI 안전/규제/일시중단" 계열 질문의 크라우드 예측 확률을 가져와, 두 진영의
거래량 가중 평균 확률 차이("Moloch Index")와 개별 시장의 급격한 확률 변동을
텔레그램으로 보고하고 종료하는 1회성 스크립트입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔나
오늘의 트렌드는 Tristan Harris(Center for Humane Technology)의 "Moloch" 단편영화로,
핵심 메시지는 "개별 AI 기업/국가는 안전을 원해도, 경쟁 구조(Moloch/다자간 경쟁 함정) 때문에
결국 속도 경쟁으로 떠밀린다"는 것입니다. 이 아이디어는 그 추상적 경고를 실제로 관측
가능한 수치로 옮긴 것입니다: Manifold 예측시장 참가자들이 베팅하는 "AGI/초지능 등장"류
질문과 "AI 일시중단/규제"류 질문의 확률 차이를, 그날그날의 "레이스가 안전을 얼마나
앞서고 있는가"에 대한 크라우드 신호로 근사합니다. 기존에 만든 "GitHub 신규 AI 오픈소스
레이더 봇"과는 완전히 다른 형태(코드 저장소 큐레이션이 아니라, 예측시장 기반 정량 지표
리포트)입니다.

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` — 이미 파이프라인에 설정되어 있는 텔레그램 봇 토큰을 그대로 사용합니다.
- `TELEGRAM_CHAT_ID` — 이미 파이프라인에 설정되어 있는 채팅 ID를 그대로 사용합니다.
- (선택) `MOLOCH_MOVE_THRESHOLD_PCT` — "급변동"으로 간주할 확률 변화 기준(퍼센트포인트, 기본값 4).

새로운 API 키는 필요 없습니다. Manifold Markets의 `search-markets` 엔드포인트는 인증 없이
호출 가능한 공개 읽기 전용 API입니다.
