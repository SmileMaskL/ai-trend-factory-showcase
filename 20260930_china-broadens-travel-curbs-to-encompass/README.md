# AI 인재 이동 제한 워치 (AI Talent Mobility Restriction Watch)

**한 줄 설명:** 전 세계 "AI/반도체 인재에 대한 여행 제한·비자 규제·이민 단속" 관련 뉴스를 매일 자동으로 스캔해서, 새로 등장한 기사만 골라 텔레그램으로 보내주는 무인 정책 리스크 알림 봇.

## 왜 이 트렌드에서 이 아이디어가 나왔나

오늘의 트렌드 기사("China broadens travel curbs to encompass family of top AI talent")는 단순한 개별 사건이 아니라, **국가가 AI 인재의 이동 자유를 정치·안보 이슈로 다루기 시작한 흐름**을 보여줍니다. 이런 흐름은:

- 글로벌 이동/이주 컨설턴트, 이민 변호사, 해외 채용 담당자에게는 실질적인 "리스크 신호"이고,
- 각국 정부의 AI 인재 유출입 정책이 앞으로도 계속 뉴스화될 가능성이 높습니다 (미국 수출통제, 중국 인재 통제, EU 비자 정책 등).

기존에 만든 프로젝트들(Moloch Index=예측시장 신호봇, GitHub OSS 큐레이션 레이더)과는 컨셉이 겹치지 않도록, 이번에는 **"요약/포스팅" 대신 "정책 신호 필터링 알림"**으로 방향을 잡았습니다. 즉, AI 자체의 기술 뉴스가 아니라 "AI 인재의 이동/거주 자유"라는 지정학적 리스크만 선별해서 걸러주는 좁고 구체적인 필터입니다.

## 동작 방식 (무인, 1회성 실행)

1. `watchlist.json`에 정의된 검색어들로 **Google News RSS**(무료, API 키 불필요, `https://news.google.com/rss/search?q=...`)를 조회합니다.
2. 각 기사 링크를 해시해서 `data/seen_articles.json`에 이미 본 기사인지 확인합니다 (중복 알림 방지, 45일 지난 항목은 자동 정리).
3. 새로 발견된 기사만 모아 최신순으로 정렬 후 최대 20건까지 텔레그램 메시지(HTML, 링크 포함)로 전송합니다.
4. 전송한 기사들을 `data/seen_articles.json`에 기록하고 즉시 종료합니다. (서버/데몬 아님, 매일 1회 실행 후 종료)

## 필요한 환경변수

| 변수 | 설명 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 기존 파이프라인에 이미 설정된 텔레그램 봇 토큰 (그대로 재사용) |
| `TELEGRAM_CHAT_ID` | 기존 파이프라인에 이미 설정된 텔레그램 채팅 ID (그대로 재사용) |

추가로 발급받아야 하는 새로운 API 키는 없습니다. Google News RSS는 키 없이 공개적으로 접근 가능합니다.
