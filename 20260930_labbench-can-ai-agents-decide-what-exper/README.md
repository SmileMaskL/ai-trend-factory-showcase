# LabBench Radar

AI 에이전트가 "다음 실험을 무엇으로 할지" 스스로 판단하는 연구(AI-for-science, 자율 실험 에이전트, 관련 벤치마크)에 대한 새 논문·HN 토론만 골라 매일 텔레그램으로 알려주는 무인 큐레이션 봇입니다.

## (b) 왜 이 트렌드에서 이 아이디어가 나왔나
오늘의 트렌드 "LabBench: Can AI agents decide what experiment to run next?"는 HN 반응이 미미(포인트 2, 댓글 0)했지만, 주제 자체는 "AI 에이전트가 과학 실험 의사결정을 대신하는 벤치마크"라는 매우 좁고 초기 단계인 니치입니다. 이런 니치는 아직 정리된 정보 소스가 없어서, 관련 논문·토론이 나올 때마다 자동으로 걸러 모아주는 것 자체가 (바이오/제약 R&D, AI-for-science 연구자 대상) 가치 있는 정보 서비스가 될 수 있습니다. 기존에 만든 프로젝트들(정책 리스크 알림, 예측시장 신호봇, GitHub 저장소 큐레이션)과는 다루는 데이터 소스(arXiv 논문 + HN 토론)와 주제(과학 실험 의사결정 AI 에이전트)가 겹치지 않도록 설계했습니다.

## 필요한 환경변수
| 변수 | 설명 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 파이프라인에 이미 설정된 텔레그램 봇 토큰 (그대로 사용) |
| `TELEGRAM_CHAT_ID` | 파이프라인에 이미 설정된 텔레그램 채팅 ID (그대로 사용) |

추가로 필요한 새 API 키는 없습니다 (arXiv API, HN Algolia API 모두 키 불필요, 무료).
