# AI 런치 영상 툴 스파이크 레이더

Hacker News 언급량을 기준으로, 오늘 어떤 AI 영상 생성 툴(Sora, Runway, Pika, Kling, Luma, Veo, HeyGen, Synthesia 등)이
"최근 7일 평균 대비 비정상적으로 급증"했는지 매일 1회 감지해서 텔레그램으로 알려주는 무인 큐레이션 레이더입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔나

오늘의 트렌드 신호는 "AI Generated launch videos are starting to get insane"
(HN, points=1, comments=0 — 아직 거의 아무도 못 본 초저신호)였습니다.
이 신호 자체는 "AI가 만든 제품 런치 영상 품질이 급격히 좋아지고 있다"는 흐름을 가리키는데,
문제는 이 분야에 툴이 너무 많고(Sora, Runway, Pika, Kling, Luma, Veo, HeyGen, Synthesia, Hailuo...) 매달 순위가 바뀐다는 점입니다.

콘텐츠 제작자/마케터/얼리어답터 입장에서 진짜 궁금한 건 "지금 이 순간 커뮤니티에서 갑자기 많이 언급되는 툴이 뭔지"이고,
이건 사람이 매일 HN을 뒤지지 않는 이상 놓치기 쉬운 신호입니다. 그래서 요약봇이나 단순 포스팅봇이 아니라,
**언급량 스파이크를 수치로 감지해 알려주는 조기 신호 레이더** 형태로 설계했습니다.
(기존 "AI 디자인/아트 툴 얼리시그널 레이더"와는 대상 영역이 영상 생성 툴로 다르고,
단순 신규 론칭 포착이 아니라 "기존 툴들 중 오늘 급등한 것"을 찾는 통계적 스파이크 탐지라는 점에서 접근 방식도 다릅니다.)

## 동작 방식

1. Hacker News Algolia Search API(무료, API 키 불필요)로 최근 24시간 동안
   각 AI 영상 툴 키워드의 story/comment 언급 건수를 조회합니다.
2. `data/history.json`에 최근 14일치 일별 언급량을 누적 저장합니다.
3. 오늘 언급량을 "직전 7일 평균"과 비교해 배율(ratio)을 계산하고,
   `오늘 2건 이상 & 배율 1.5배 이상`인 툴만 "스파이크"로 판정합니다.
4. 스파이크가 있으면 상위 5개 툴 + 관련 HN 인기글 링크를 텔레그램으로 전송합니다.
5. 스파이크가 없으면 "오늘 언급량 상위 3개 툴"을 참고용으로 보냅니다.
6. 1회 실행 후 종료됩니다 (서버/데몬 아님).

## 필요한 환경변수

| 변수명 | 설명 | 비고 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | 텔레그램 봇 토큰 | 기존 파이프라인에 이미 설정되어 있으면 그대로 재사용 |
| `TELEGRAM_CHAT_ID` | 알림을 받을 챗/채널 ID | 기존 파이프라인에 이미 설정되어 있으면 그대로 재사용 |
| `AI_VIDEO_KEYWORDS` (선택) | 쉼표로 구분한 커스텀 키워드 목록 | 설정 안 하면 기본 13개 툴 키워드 사용 |

새로 발급받아야 하는 API 키는 없습니다 (HN Algolia 검색은 키 없이 무료로 사용 가능).
텔레그램 환경변수가 비어 있으면 전송을 스킵하고 콘솔에 결과만 출력하므로, 파이프라인이 실패하지는 않습니다.
