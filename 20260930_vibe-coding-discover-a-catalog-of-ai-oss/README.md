# MCP & AI Agent OSS Radar

## (a) 한 줄 설명
GitHub에서 매일 새로 뜨는 MCP(Model Context Protocol) 서버 / AI 에이전트 스킬 / RAG 프레임워크 오픈소스 저장소를 검색해, 이전에 알린 적 없는 것만 골라 텔레그램으로 보내주는 큐레이션 알림 봇입니다.

## (b) 왜 이 트렌드에서 이 아이디어가 나왔는가
오늘의 트렌드인 "Vibe Coding Discover"는 Agents/MCP/Skills/RAG 관련 AI OSS를 모아놓은 카탈로그 웹사이트입니다 (HN points=1, comments=0으로 신호는 약하지만, MCP/에이전트 OSS 생태계가 빠르게 커지고 있다는 방향성은 유효합니다).
동일한 정적 카탈로그 웹사이트를 또 만드는 대신, "신규 카탈로그 사이트" 대신 "신규 항목 알림 리포트"로 방향을 바꿨습니다. 즉, 카탈로그를 만드는 것이 아니라 카탈로그에 들어갈 법한 신규/급상승 OSS를 매일 자동으로 스캔해서 먼저 알려주는 필터 역할을 합니다. 이렇게 하면 MCP 서버나 에이전트 스킬을 만드는 개발자, 또는 최신 도구를 빨리 써보고 싶은 얼리어답터에게 실질적인 가치를 줍니다.

## (c) 필요한 환경변수
| 변수 | 필수 여부 | 설명 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | 선택 (설정되어 있으면 텔레그램으로 전송, 없으면 콘솔 출력으로 자동 대체) | 알림을 보낼 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 선택 (설정되어 있으면 텔레그램으로 전송, 없으면 콘솔 출력으로 자동 대체) | 알림을 받을 채팅 ID |
| `GITHUB_TOKEN` | 선택 | GitHub Search API의 무인증 rate limit(분당 10회)을 늘리고 싶을 때만 설정. 없어도 정상 동작합니다 (인증 없이도 매일 1회 실행에는 충분). |

기존 파이프라인에는 `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`가 이미 설정되어 있어 평소에는 텔레그램으로 전송됩니다. 다만 두 값 중 하나라도 없는 실행 환경(예: 단독 검증 실행)에서도 스크립트가 실패하지 않도록, 이 경우에는 동일한 리포트를 표준 출력(stdout)으로 출력하고 정상 종료합니다. 새로운 유료 API 키는 필요하지 않습니다. 검색 대상 키워드는 `watchlist.json`에서 자유롭게 추가/수정할 수 있습니다.

## (d) 실행 방법
```bash
pip install requests   # 이미 설치되어 있다면 생략 가능
export TELEGRAM_BOT_TOKEN=xxx   # 없어도 실행은 되며, 이 경우 콘솔에 리포트가 출력됩니다
export TELEGRAM_CHAT_ID=xxx
python run.py
```
