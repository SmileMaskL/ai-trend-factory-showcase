# Dynamic Price Watchdog 💸

**AI 동적 가격 시대에 대응하는 개인용 가격 감시견: 하루 한 번 감시 목록의 가격을 기록하고, 변동·90일 최저가·목표가 도달·"가격이 자주 바뀌는 상품"을 텔레그램으로 알립니다.**

## 왜 이 트렌드에서 나왔나

- 트렌드: *"McDonald's Is Using AI to Dynamically Price Its Burgers"* — 맥도날드 같은 대형 소매업체가 AI로 가격을 실시간으로 조정하기 시작했습니다.
- 가격이 수시로 바뀌면 소비자는 **"지금이 싼 건지 비싼 건지"** 판단할 기준을 잃습니다. 기업은 AI로 가격을 최적화하는데, 개인은 기록조차 없습니다.
- 그래서 반대편 도구를 만들었습니다. **가격을 매일 기록해 기준선을 만들고**, 변동이 생길 때만 알려주는 무료 감시기입니다. 30일 안에 가격이 여러 번 바뀐 상품은 "⚡ 동적 가격 후보"로 따로 보여 줍니다.
- 기본 감시 목록은 **Steam 공개 스토어 API**(키 불필요)를 사용해 설치 직후 바로 동작합니다. 같은 게임을 US/KR 지역별로 추적해 **지역별 가격 차이**도 볼 수 있습니다.
- 일반 쇼핑몰 URL도 등록할 수 있습니다. 페이지의 JSON-LD(`schema.org/Offer`), `product:price:amount` meta, `itemprop="price"`에서 가격을 자동 추출하고, 실패하면 `price_regex`로 직접 지정할 수 있습니다.

## 필요한 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ (파이프라인에 이미 설정됨) | 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` | ✅ (파이프라인에 이미 설정됨) | 알림 받을 채팅/채널 ID |
| `PRICE_WATCH_ALWAYS_NOTIFY` | 선택 | `1`이면 변동이 없는 날에도 현재가 요약 전송 |

그 외 API 키는 필요 없습니다. 텔레그램 변수가 없으면 콘솔에만 출력하고 정상 종료합니다.

## 실행 방법

```bash
python run.py
```

- 의존성: Python 3.8+ 표준 라이브러리 + `requests`
- 한 번 실행하면 수집 → `data/history.json` 저장 → (필요할 때만) 텔레그램 전송 → 종료합니다. 서버나 루프는 없습니다.
- **첫 실행**에서는 "🆕 기준가 등록" 메시지가 옵니다. 이틀째부터 변동 알림이 오기 시작합니다.
- 같은 날 다시 실행하면 오늘 기록을 덮어쓰고, 전날과 비교합니다(중복 누적 없음).
- 종료 코드: 모든 항목 수집에 실패했거나 텔레그램 전송에 실패하면 `1`, 그 외에는 `0`입니다.

### 감시 목록 편집 (`watchlist.json`)

```json
{ "type": "steam", "appid": 413150, "cc": "kr", "target_price": 10000 }
{ "type": "url", "url": "https://shop.example/p/1", "name": "내 상품", "target_price": 49.99 }
{ "type": "url", "url": "...", "price_regex": "class=\"price\">\\$([\\d,.]+)", "currency": "USD" }
```

- `appid`: Steam 스토어 URL `store.steampowered.com/app/<appid>/`의 숫자
- `cc`: 국가 코드(us, kr, jp, de …) → 해당 지역 가격/통화
- `enabled: false`: 일시적으로 끔
- 주의: 봇 차단(Cloudflare 등)이 강한 대형 쇼핑몰은 수집에 실패할 수 있으며, 실패한 항목은 리포트 하단에 표시됩니다. 대상 사이트의 이용약관과 robots.txt를 지켜 주세요. 하루 1회, 요청 간격 1.5초로 부하를 최소화했습니다.

## 수익화 전략 (현실적인 버전)

과장 없이 말하면, 이 코드 자체로 큰돈은 되지 않습니다. 대신 적은 비용으로 시도할 수 있는 경로는 아래와 같습니다.

1. **틈새 가격 알림 텔레그램 채널 + 제휴 링크** (난이도 ★★☆, 세팅 2~4시간, 성장에 3~6개월)
   - 예: "인디게임 지역별 최저가", "한국 가격 기준 Steam 역대 최저 알림" 같은 채널을 운영합니다.
   - Steam 자체에는 제휴 프로그램이 없으므로 Humble Bundle Partner, Fanatical, Green Man Gaming 같은 키 판매처의 제휴 링크를 함께 붙여야 합니다.
   - 구독자 1,000명 전후부터 월 몇만 원 수준이 현실적입니다. 콘텐츠 품질(선별)이 핵심입니다.
2. **소규모 판매자 대상 "경쟁사 가격 감시" 대행** (난이도 ★★★, 고객당 세팅 1~2시간)
   - 스마트스토어나 Shopify 셀러에게 경쟁 상품 10~30개의 일일 가격 변동 리포트를 텔레그램으로 제공합니다.
   - 월 1~3만 원 정도의 소액 구독이 현실적입니다. 사이트마다 `price_regex` 유지보수가 필요하다는 점이 비용입니다.
   - 고객 3~5명을 확보하는 데 1~2개월 정도의 영업이 필요할 것으로 예상됩니다.
3. **데이터 콘텐츠화** (난이도 ★☆☆, 월 2~3시간)
   - 누적된 `history.json`으로 "이번 달 가격이 가장 자주 바뀐 상품", "한국 vs 미국 가격 차이" 같은 글을 블로그나 뉴스레터에 올리고 애드센스나 제휴 수익을 얻습니다.
   - 데이터가 쌓이기까지 최소 1~2개월이 필요합니다.

리스크: 크롤링 대상 사이트의 구조 변경이나 차단으로 수집이 실패할 수 있고, 제휴 프로그램 승인은 보장되지 않습니다. Steam API도 비공식 공개 엔드포인트이므로 사양이 바뀔 수 있습니다.
