# AI 구독/가격 변경 레이더 (HN 기반)

## 한 줄 설명
Hacker News에서 주요 AI 서비스(OpenAI, Anthropic, xAI, Google, Perplexity, Midjourney, GitHub Copilot, Cursor 등)의 "구독/가격" 관련 신규 게시물만 교차 감지해, 새로 올라온 글만 텔레그램으로 알려주는 무인 레이더입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔나
오늘의 트렌드 "The X Subscription"(xAI의 신규 구독 상품, HN points=1/comments=0)은 신호 자체는 약하지만, "AI 서비스가 구독 상품/가격 정책을 바꾼다"는 패턴은 앞으로도 반복적으로 발생합니다. 개별 토픽(이 글 하나)을 쫓기보다 "AI 구독·가격" 카테고리 전체를 HN에서 상시 레이더링하면, 앞으로 나올 비슷한 신호(가격 인상, 신규 플랜, 무료 티어 변경 등)를 꾸준히 포착할 수 있습니다. 기존에 만든 프로젝트들(보안 사고, 컴파일러 트렌드, 벤치마크, 여행 규제, GitHub 트렌딩 등)과 주제가 겹치지 않도록 "구독/가격" 전용 니치로 설계했습니다.

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` : 기존 파이프라인에 이미 설정되어 있는 텔레그램 봇 토큰 (그대로 사용)
- `TELEGRAM_CHAT_ID` : 기존 파이프라인에 이미 설정되어 있는 텔레그램 채팅 ID (그대로 사용)

별도의 새 API 키는 필요하지 않습니다 (HN Algolia 검색 API는 키 없이 무료로 사용 가능).

## 실행 방법
```bash
python3 run.py
```
- 최근 48시간 내 올라온 HN 스토리 중 `watchlist.json`에 정의된 검색어와 일치하는 글을 검색합니다.
- `data/seen_ids.json`에 이미 보낸 글의 ID를 저장해 중복 알림을 방지합니다.
- 새로운 글이 없으면 조용히 종료합니다. 새로운 글이 있으면 텔레그램으로 각 건을 전송합니다.
- 매일 1회 실행되는 배치 스크립트이며, 서버/데몬으로 띄우지 않습니다.

## 커스터마이징
`watchlist.json`의 `queries` 배열에 검색어(회사명 + "pricing"/"subscription" 등)를 추가/삭제하면 감지 대상을 조절할 수 있습니다.

## 현실적인 수익화 전략
- **대상**: AI 도구 가격 변화에 민감한 PM, 그로스 마케터, "AI 툴 가격 비교" 뉴스레터 운영자.
- **방법**: 이 레이더가 모은 신호를 매주 정리해 뉴스레터(무료 Substack 등)로 발행 → 광고/스폰서십 또는 유료 구독(월 $3~5) 전환을 시도.
- **난이도/소요 시간**: 코드 자체는 이미 완결되어 추가 개발이 거의 필요 없음(난이도 낮음). 다만 HN에 AI 가격 관련 글이 매일 올라오지는 않아 신호 빈도가 낮을 수 있고, 유의미한 뉴스레터로 키우려면 최소 4~8주간 수동 큐레이션/검증이 필요하며 구독자 확보에는 추가로 수개월이 걸릴 수 있습니다. "돌리면 바로 돈이 되는" 구조는 아니고, 수집된 신호를 사람이 가공해 콘텐츠화해야 수익화가 가능한 수준입니다.
