# AI 브라우저 에이전트 프라이버시 워치

## 한 줄 설명
ChatGPT Atlas, Microsoft Copilot, Perplexity Comet 등 "브라우저 탭/방문 기록/클립보드를 읽는 AI 에이전트" 기능과 관련된 신규 신호를, 공식 브라우저 릴리스노트 RSS + HackerNews 토론에서 교차 감지해 새로운 것만 텔레그램으로 알려주는 무인 레이더입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔나
오늘의 트렌드 "ChatGPT can peek at your Chrome tabs now"는 AI 브라우저/에이전트가 사용자의 탭·방문 기록 같은 민감한 브라우징 데이터를 들여다보는 기능이 빠르게 확산되고 있음을 보여줍니다. 이 기능 자체(ChatGPT Atlas)를 1회성으로 다루기보다, "AI가 브라우저 탭/기록/클립보드를 읽는다"는 패턴을 상시 감지하는 니치 레이더로 설계했습니다. 기존에 만든 "AI 에이전트 보안 사고(CVE 기반)" 프로젝트와는 달리, 이 프로젝트는 CVE/취약점이 아니라 (1) 브라우저 공식 릴리스노트에서 먼저 터지는 기능 발표, (2) HN에서의 커뮤니티 반응을 동시에 추적해 "다음 프라이버시 논쟁거리"를 더 빨리 포착하는 데 초점을 둡니다.

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` : 기존 파이프라인에 이미 설정되어 있는 텔레그램 봇 토큰 (그대로 사용)
- `TELEGRAM_CHAT_ID` : 기존 파이프라인에 이미 설정되어 있는 텔레그램 채팅 ID (그대로 사용)

별도의 새 API 키는 필요하지 않습니다 (HN Algolia 검색 API, 각 브라우저 공식 RSS 피드 모두 인증 없이 무료로 사용 가능).
