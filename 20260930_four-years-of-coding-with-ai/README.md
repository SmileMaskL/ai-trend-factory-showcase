# AI 코딩 도구 릴리스 레이더

**한 줄 설명:** Claude Code, Codex CLI, Gemini CLI, Aider, Cline 같은 AI 코딩 에이전트의 새 GitHub 릴리스와 Hacker News 화제 글을 매일 한 번 모아 텔레그램으로 보내 주는 무료 자동화 도구입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔나
트렌드 글 "Four Years of Coding with AI"(av.codes)는 여러 해 동안 AI 코딩 도구와 에이전트 환경(agentic setup)을 계속 바꿔 온 경험을 다룹니다. 이런 글에서 반복되는 문제가 하나 있습니다. **도구가 너무 빨리 바뀌어서 따라가기 어렵다**는 점입니다. 주요 에이전트 CLI는 거의 매주 새 버전을 내고, 모델 지원이나 기능, 동작 방식이 조용히 바뀝니다.
글을 요약하는 대신, 에이전트 환경을 쓰는 개발자에게 실제로 필요한 **"내가 쓰는 도구가 바뀌었는지" 알려 주는 레이더**를 만들었습니다.

## 동작 방식
1. `repos.txt`에 적힌 GitHub 저장소의 최신 릴리스를 조회합니다(공개 API, 무료).
2. HN Algolia API로 최근 36시간 동안 AI 코딩 관련 글 중 점수가 30점 이상인 글을 찾습니다.
3. 이전에 보낸 적 없는 항목만 텔레그램 메시지 하나(길면 여러 개)로 보냅니다.
4. 전송에 성공한 경우에만 `state.json`에 기록하므로, 실패하면 다음 실행 때 다시 시도합니다.
5. 모든 작업이 끝나면 프로그램이 종료됩니다. 데몬이나 서버, 무한 루프는 없습니다.

## 필요한 환경변수
| 이름 | 필수 | 설명 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | 텔레그램 봇 토큰 (파이프라인에 이미 설정됨) |
| `TELEGRAM_CHAT_ID` | ✅ | 받을 채팅/채널 ID (파이프라인에 이미 설정됨) |
| `GITHUB_TOKEN` | 선택 | 저장소를 수십 개 이상 추적할 때만 필요 (비인증 한도: 시간당 60회) |
| `RADAR_*` | 선택 | 조회 기간, 점수 기준 등 (`.env.example` 참고) |

텔레그램 변수가 없으면 다이제스트를 콘솔에만 출력하고 종료 코드 1로 끝납니다.

## 실행 방법
```bash
python run.py
```
- 의존성: Python 3.8+ 표준 라이브러리 + `requests`
- 추적 대상을 바꾸려면 `repos.txt`를 수정하세요.
- 처음 실행할 때는 너무 많은 메시지가 한꺼번에 오지 않도록 최근 7일 안의 릴리스만 보냅니다.

## 현실적인 수익화 전략
과장 없이 말하면, 이 도구만으로 바로 돈이 되지는 않습니다. **공개 채널을 만들어 독자를 모으는 것**이 먼저입니다.

1. **공개 텔레그램 채널 운영** (난이도: 하, 준비 1~2시간)
   `TELEGRAM_CHAT_ID`를 공개 채널로 바꾸고 HN, Reddit(r/ChatGPTCoding, r/ClaudeAI), X, 국내 개발 커뮤니티에 소개합니다. 구독자 수백 명을 모으는 데 보통 1~3개월이 걸리고, 성과가 전혀 없을 수도 있습니다.
2. **스폰서 고정 메시지 / 제휴 링크** (난이도: 중)
   구독자가 1,000명 이상은 되어야 의미가 있습니다. 개발 도구 제휴 프로그램(호스팅, IDE 확장 등)이나 소규모 스폰서 게시물 수익은 현실적으로 월 $0~$100 수준입니다.
3. **팀/회사용 커스텀 레이더** (난이도: 중, 건당 2~4시간)
   `repos.txt`를 고객이 쓰는 도구 스택에 맞춰 바꾸고 사내 텔레그램이나 Slack으로 보내는 설정을 소액 프리랜스 작업(건당 $20~$100)으로 제공합니다. 크몽, Fiverr 등에 올릴 수 있습니다.
4. **주간 뉴스레터로 확장** (난이도: 중~상, 매주 1~2시간 편집)
   매일 쌓인 데이터를 바탕으로 사람이 직접 코멘트를 붙여 무료 뉴스레터(Substack, Buttondown 무료 플랜)로 발행합니다. 신뢰가 쌓인 뒤 유료 구독을 시도할 수 있지만, 수익은 6개월 이상 꾸준히 운영해야 기대할 수 있습니다.

**예상:** 첫 수익까지 최소 2~3개월이 걸리고, 초기 월수익은 $0~$50 수준을 현실적인 기대치로 잡으세요. 운영 비용은 $0입니다.
