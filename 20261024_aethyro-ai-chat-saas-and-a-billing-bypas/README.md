# SaaS 빌링 로직 취약점 디스클로저 레이더

## (a) 한 줄 설명
Hacker News에서 "자기 자신의 SaaS를 공격해서 찾은 결제/구독 로직 버그"를 공개하는 글(=billing bypass disclosure)을 매일 자동으로 스캔해, 아직 널리 퍼지기 전(저포인트 구간)에 텔레그램으로 알려주는 무인 큐레이션 레이더입니다.

## (b) 이 트렌드에서 이 아이디어가 나온 이유
오늘의 트렌드 "Aethyro – AI chat SaaS, and a billing bypass I found by attacking my own product"는 HN points=1, comments=0으로 아직 아무도 주목하지 않은 글입니다. 이 글의 핵심은 단순 버그 리포트가 아니라, **"창업자가 자기 제품을 공격자 시점에서 테스트해 결제 로직 취약점을 발견하고 공개한다"**는 하나의 장르(genre)입니다. 이런 글은 ① SaaS를 운영하는 개발자에게는 "내 결제 로직도 같은 패턴으로 뚫릴 수 있다"는 경각심을 주는 실전 체크리스트 소스이고, ② 보안/버그바운티 관심층에게는 흥미로운 케이스 스터디입니다. 기존에 만든 프로젝트들은 "책임전가 조항", "가격 변경 공지", "에이전트 보안 사고(NVD 연동)" 등을 다뤘지만, **"SaaS 창업자의 자가 결제 취약점 디스클로저"**라는 좁고 반복되는 장르를 전담으로 걸러내는 레이더는 없었기에 이 틈새를 채웁니다. 실제 취약점을 악용하는 방법을 생성하거나 전파하지 않고, 이미 공개된 디스클로저 글의 제목/링크/신호만 큐레이션합니다.

## (c) 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` : 기존 파이프라인에 등록된 텔레그램 봇 토큰 (그대로 재사용)
- `TELEGRAM_CHAT_ID` : 기존 파이프라인에 등록된 텔레그램 채팅 ID (그대로 재사용)

추가로 필요한 API 키는 없습니다. HN Algolia 검색 API(`https://hn.algolia.com`)는 키 없이 무료로 사용 가능합니다.
