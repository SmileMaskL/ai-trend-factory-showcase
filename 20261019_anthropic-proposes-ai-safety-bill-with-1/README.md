# AI 안전법안 구체성 레이더 (AI Safety Bill Concreteness Radar)

## 한 줄 설명
Hacker News에서 AI 규제/안전법/책임 관련 글과 댓글을 모아, "달러 금액·사망자 수·퍼센트" 같은 서로 다른 유형의 구체적 숫자가 2종류 이상 동시에 등장하는 글만 걸러내어 텔레그램으로 알려주는 무인 레이더입니다. 즉 "AI 규제 논의가 말뿐인 단계를 지나 실제 숫자가 박힌 법안/정책 디테일 단계로 넘어갔는가"를 자동 감지합니다.

## 왜 이 트렌드에서 이 아이디어가 나왔나
오늘의 트렌드 "Anthropic proposes AI safety bill with $1B / 50-death threshold"(HN, points=3/comments=0)는 신호 자체는 약하지만 구조가 독특합니다. 대부분의 AI 안전 담론은 "위험하다", "규제가 필요하다" 식으로 추상적인데, 이 기사는 **구체적인 달러 금액($1B)과 구체적인 사망자 수 임계값(50명)**이라는, 서로 다른 두 종류의 하드 넘버가 동시에 들어간 흔치 않은 사례입니다.

이 프로젝트는 그 "구체성"이라는 속성 자체를 측정 가능한 신호로 바꿨습니다. 블랙리스트의 기존 프로젝트들(AI 말투 레이더, PyPI 글루트 레이더, 브라우저 에이전트 프라이버시 워치, 면접 정책 레이더, 구독/가격 변경 레이더, breaking change 레이더, 보안 사고 레이더, 실험 벤치마크 레이더, 인재 이동 제한 레이더, Moloch Index, GitHub OSS 큐레이션 레이더 등)은 전부 "특정 주제의 뉴스/이벤트를 감지"하는 데 초점이 있지만, 이 프로젝트는 주제가 아니라 **담론의 구체성(언어의 추상성 vs 숫자화 정도)** 자체를 스코어링한다는 점에서 완전히 다른 축입니다. 데이터 소스(HN Algolia Search API, 글+댓글 텍스트 정규식 분석)도 겹치지 않습니다.

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` : 기존 파이프라인에 이미 설정되어 있는 텔레그램 봇 토큰 (그대로 사용)
- `TELEGRAM_CHAT_ID` : 기존 파이프라인에 이미 설정되어 있는 텔레그램 채팅 ID (그대로 사용)

별도의 새 API 키는 필요하지 않습니다. HN Algolia Search API는 인증 없이 무료로 사용 가능합니다.
