# AI 크리에이티브 툴 얼리시그널 레이더

## 한 줄 설명
Hacker News(Algolia 검색 API, 무료/무키)에서 "AI + 디자인/아트/크리에이티브" 키워드가
동시에 등장하면서 아직 포인트가 낮은(= 아직 널리 퍼지지 않은) 신규 툴 론칭 신호만
걸러내어 텔레그램으로 매일 1회 알려주는 무인 큐레이션 레이더입니다.

## 왜 이 트렌드에서 이 아이디어가 나왔는가
오늘의 트렌드 `Inkspo` (inkspo.ai, HN points=1, comments=1)는 포인트/댓글이 거의 없는
"아직 아무도 주목하지 않은" AI 크리에이티브(잉크/디자인 영감) 툴 론칭 글이었습니다.
즉 신호 자체보다 "이런 저포인트 AI 디자인 툴 론칭이 매일 조용히 올라온다"는 패턴이
핵심이었고, 이를 일반화하면 "AI × 디자인/아트 계열 신규 툴을 남들보다 먼저 포착"하는
레이더로 확장할 수 있습니다. 이미 존재하는 "AI 에이전트용 제품 런칭 레이더"나
"GitHub MCP 큐레이션 레이더"와는 대상(크리에이티브/디자인 툴)과 소스 필터링 방식
(저포인트 얼리시그널 전용)이 달라 중복되지 않습니다.

## 필요한 환경변수
- `TELEGRAM_BOT_TOKEN` : 기존 파이프라인에 이미 설정된 텔레그램 봇 토큰 (재사용)
- `TELEGRAM_CHAT_ID` : 기존 파이프라인에 이미 설정된 텔레그램 채팅 ID (재사용)

새로 발급받아야 하는 API 키는 없습니다. HN Algolia 검색 API(`hn.algolia.com`)는
무료·무인증으로 호출 가능합니다.
